# Algoritmos en Lenguaje Natural

## 1. Sueldo base

```
Inicio del programa
    Mostrar mensaje de bienvenida
    Repetir:
        Solicitar al usuario su nombre
        Solicitar al usuario su sueldo base
        Si el valor ingresado no es un número válido, mostrar mensaje de error y volver a pedirlo
        Si el sueldo es menor o igual a cero, mostrar mensaje de error y volver a pedirlo
        Si el sueldo es un número mayor a cero:
            Calcular el descuento de salud (sueldo por 0.12)
            Calcular el descuento de pensión (sueldo por 0.165)
            Calcular el descuento de ARL (sueldo por 0.0125)
            Sumar los tres descuentos para obtener el total de descuentos
            Restar el total de descuentos al sueldo para obtener el sueldo neto
            Mostrar en pantalla el nombre, el sueldo, los descuentos y el sueldo neto
            Salir del ciclo
fin del programa
```

## 2. Área del triángulo

```
Inicio del programa
    Mostrar mensaje de bienvenida
    Repetir:
        Solicitar al usuario la medida de la base del triángulo
        Solicitar al usuario la medida de la altura del triángulo
        Si alguno de los valores ingresados no es un número válido, mostrar mensaje de error
        Si la base o la altura son menores o iguales a cero, mostrar mensaje de error
        Si la base y la altura son mayores a cero:
            Calcular el área multiplicando la base por la altura y dividiendo entre dos
            Mostrar el área en pantalla
fin del programa
```

## 3. Área del cuadrado

```
Inicio del programa
    Mostrar mensaje de bienvenida
    Repetir:
        Solicitar al usuario la longitud del lado del cuadrado
        Si el valor ingresado no es un número válido, mostrar mensaje de error
        Si el lado es menor o igual a cero, mostrar mensaje de error
        Si el lado es un número mayor a cero:
            Calcular el área multiplicando el lado por sí mismo
            Mostrar el área en pantalla
fin del programa
```
